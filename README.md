# The Sales House — SalesOS

Internal sales operations platform. Start with `docs/SALESOS_PLAN.md`.

```bash
npm install
npm run dev        # http://localhost:3000
```

- `/` — the Phase 0 clickable prototype (sample data, demo role switcher bottom-left).
- `/progress` — build progress tracker.

Prototype data is fake and in-memory; nothing is persisted or sent anywhere.
